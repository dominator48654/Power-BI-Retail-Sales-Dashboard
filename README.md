# 🏬 Retail Sales & Store Performance Dashboard  

## 📌 Project Overview  
This project is a **Power BI Dashboard** built to analyze retail sales performance, store distribution, and cost insights across the United States. The dashboard provides **executive-level KPIs**, **geographic insights**, and **store-type analysis** to help decision-makers optimize sales strategies and operational efficiency.  

---

## 📊 Key Features  
✔️ Executive KPIs – YTD Sales, Gross Profit, Total Sales  
✔️ Geographic Analysis – Sales by State & Store Location (Map View)  
✔️ Store-Type Performance – CORE, DIGITAL, LOCAL comparison  
✔️ Department Insights – Clothing, Electronics, Garage, Kitchen, Other  
✔️ KPI Tracking vs Targets – Goal performance with variance indicators  
✔️ Cost Analysis – Rent vs Store Size correlation  
✔️ Interactive Filters – Department slicer, Date slicer, StoreType filters  
✔️ Drill-through Pages & Tooltips – Deeper exploration of state/store data

## 📈 Insights Gained  
- Clothing & Electronics are the **top-performing departments**.  
- CORE stores generate **the highest sales volume**, while LOCAL stores lag behind.  
- Rent is **positively correlated with store size**, impacting profitability.  
- Some states consistently **underperform against targets**, highlighting opportunities for optimization.
